Course ID: DB-DW-101 Standard: WCAG 2.2 Level AA / PDF-UA Conformance Estimated Reading Time: 12 Minutes Audio Companion: 32 kbps Opus Low-Data Stream

1. Module Overview & Learning Outcomes

Welcome to the foundation module of the Digital Workplace Skills program. This course is specially engineered for learners with diverse visual, hearing, motor, and cognitive abilities, as well as learners in low-connectivity 3G mobile environments across Ethiopia.

By completing this study handout alongside the interactive media lesson, you will master:

  • Universal Keyboard Navigation: Operating distributed digital work tools without a mouse.
  • Screen Reader Interaction: Utilizing NVDA on desktop and TalkBack on Android to navigate structured documents and data portals.
  • Accessible Remote Collaboration: Composing descriptive alternative text, thread etiquette, and asynchronous status communication.
  • Offline Learning Strategy: Utilizing compressed 3G study packages to continue training during power or network outages.

2. Universal Media Player Keyboard Shortcuts

The Savanna Accessible Media Player embedded in your learning management system implements single-key and modifier-free controls conforming to WCAG 2.2 Guideline 2.1 (Keyboard Accessible).

Keyboard Key Action Triggered Accessibility Purpose
Space or k Toggle Play / Pause Primary playback control with zero focus drift.
j / l Seek Backward / Forward 10s Efficient review of technical and instructional phrases.
0 or Home Restart Lesson Instantly return to the lesson beginning.
c Cycle Captions (EN • AM • Off) Dual-language synchronized text for Deaf learners.
s Toggle Ethiopian Sign Language (ESL) Dock or float secondary EthSL signer window.
v Audio Description (AD) Stream Spoken descriptions of on-screen visual demonstrations.
m Mute / Unmute Audio Immediate volume cut for distraction-free study.
> / < Increase / Decrease Speed (0.75x - 2x) Pace pacing for comprehension and cognitive needs.

3. Accessible Feedback & Verification Workflow

In modern inclusive workplaces, peer review and co-design validation occur before code, documentation, or marketing assets are published.

Key Workplace Takeaway: Never share an image, spreadsheet graph, or interface mockup without accompanying alternative text. If a screenshot contains crucial text or data, transcribe that text in the message body so colleagues using screen readers can participate equally.

4. Low-Bandwidth 3G Study Protocol

High-definition streaming video can consume upwards of 200 MB per lesson, which can be prohibitive on prepaid Ethiopian mobile data packages. Our architecture provides a compressed 3.2 MB Study Package:

  1. 32 kbps Opus Audio Track: Captures crystal-clear speech at a fraction of the bitrate of video.
  2. Interactive WebVTT Captions: Provides text synchronization with minimal byte overhead (< 2 KB).
  3. Standalone Semantic Document: This lightweight HTML file and its companion tagged PDF allow reading without network latency.
  4. Service Worker Cache: Once downloaded, the entire module can be studied in airplane mode.

5. Module Self-Assessment

Review these questions to prepare for the Level 2 practical evaluation:

  • Question 1: What key combination allows a screen reader user to quickly jump back 10 seconds without disrupting playback? Answer: Press the j key.
  • Question 2: Why is semantic HTML preferred over plain text or generic <div> tags for course handouts? Answer: Semantic tags establish a structured hierarchy that screen reader headings and landmarks can announce directly.
  • Question 3: How does the dual Ethiopian-Gregorian calendar format assist local employment compliance? Answer: It ensures date transparency across Ethiopian government fiscal systems (e.g., 2018 E.C.) and international remote partners (2026 G.C.).
